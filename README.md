# BRAINet

PyTorch implementation of BRAINet for three-class EEG classification of
unresponsive wakefulness syndrome (UWS), minimally conscious state minus
(MCS−), and minimally conscious state plus (MCS+).

This repository contains BRAINet, preprocessing, configuration, training, and
epoch-/subject-level evaluation. It follows the final manuscript's method
description. Patient data and pretrained weights are not included.

## Structure

```text
BRAINet/
├── dataset/
│   └── dataset.py       # Input validation, normalization, patient-wise splits
├── models/
│   └── BRAINet.py       # RegionCNN, spectral embedding, attention, ApEn fusion
├── preprocess/

├── utils/
│   ├── channels.py      # Exact input order, regions, and class labels
│   ├── features.py      # Channel-wise approximate entropy
│   └── metrics.py       # Epoch, patient, fold, and pooled OOF evaluation
├── .gitignore
├── LICENSE
├── README.md

├── config.json
├── master.py            # Experiment entry point
└── operate.py           # Fixed-duration training and inference
```

## Installation

Run all commands from the repository root. Python 3.8.18 is the tested environment.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

For GPU execution, install a PyTorch build compatible with your CUDA runtime.
CPU execution is supported. The main experiment uses Adam, learning rate
`1e-4`, weight decay `1e-4`, batch size `64`, and exactly `25` training epochs.

## Data preparation

Use de-identified patient IDs, consistent across every recording from the same
patient. Labels are `0 = UWS`, `1 = MCS−`, `2 = MCS+`.

For raw recordings, create a CSV with `subject_id,label,path` columns:

```csv
subject_id,label,path
S001,0,raw/S001.vhdr
S002,1,raw/S002.vhdr
S003,2,raw/S003.vhdr
```

Paths are relative to the CSV location, or absolute. MNE reads the recordings
in volts. Recordings must be sampled at 1000 Hz and contain the 63 channels
listed in `utils/channels.py`. Channel names must match exactly; no channels
are silently renamed or interpolated. BrainVision sidecar files must be present.

```bash
python -m preprocess.preprocess data/recordings.csv data/epochs.npz
python -m utils.features data/epochs.npz data/epochs_apen.npz --jobs 4
```

Preprocessing selects and orders the 63 channels, applies a 50 Hz notch and
1–40 Hz zero-phase FIR band-pass, segments non-overlapping 2-second epochs,
rejects any epoch exceeding **±180 µV**, applies common-average reference,
resamples to 250 Hz, and standardizes each epoch/channel over time.
Incomplete trailing epochs are discarded. Annotation-based rejection is not
added. Epoch counts and retained original epoch indices are saved in a JSON
sidecar. Filter length and transition bands use the pinned MNE defaults.

Alternatively, supply an NPZ file containing these arrays (no pickled objects):

| Key | Shape/type | Meaning |
| --- | --- | --- |
| `x` | float, `(N, 63, 500)` | Preprocessed EEG epochs |
| `y` | integer, `(N,)` | Labels 0, 1, or 2 |
| `subject_id` | Unicode strings, `(N,)` | Patient ID for each epoch |
| `channels` | Unicode strings, `(63,)` | Exact `utils.channels.CHANNELS` order |
| `sfreq` | scalar | `250` |
| `apen` | optional float, `(N, 63)` | ApEn in the same epoch/channel order |

ApEn uses EntropyHub with embedding dimension `m=2`, delay 1, and tolerance
`0.2 × population SD`; constant signals have ApEn zero. When omitted, it is
computed before training without labels. Existing ApEn must be computed from
the same processed epochs. There is no cross-patient normalization or fitting
in this feature step.

## Training

```bash
python master.py --data data/epochs_apen.npz --output results/brainet --device cuda:0
```

Omit `--device` to use CPU. By default, a five-fold split is generated by
stratifying one row per patient, then expanding patient assignments to epochs.
Each class needs at least five patients. All epochs from a patient remain in
one fold. The split is saved and checked for overlap, label consistency, and
complete out-of-fold coverage.

To reuse supplied patient assignments:

```bash
python master.py --data data/epochs_apen.npz --output results/repeat \
  --splits results/brainet/splits.json --device cuda:0
```

The split JSON contains `folds`, a list of objects with `fold` (1-based),
`train` (patient ID strings), and `test` (patient ID strings). Train and test
must cover the entire cohort, be disjoint, and test each patient exactly once.
Seed `666` is the default; change it in `config.json` if needed.

The model is evaluated only after the final training epoch. There is no
validation subset, early stopping, or test-based checkpoint selection. Existing
output directories are rejected to avoid mixing runs.

## Evaluation and saved outputs

Each run saves the effective settings, input/split SHA256 hashes, patient
assignments, ApEn, final checkpoints, training losses, and epoch probabilities.
All patients contribute to OOF predictions once. Patient probabilities are
the arithmetic mean of that patient's epoch probabilities; `argmax` determines
the class. Ties use the first class in label order.

```bash
python -m utils.metrics results/brainet/oof_epoch_predictions.csv results/brainet/recomputed_metrics.json
```

`metrics.json` reports epoch-/patient-level BA, macro precision, weighted
recall, macro specificity, macro-F1, weighted-F1, macro OvR AUC, per-class
recall/specificity, confusion matrices, and multiclass Brier score. Brier score
is the mean **sum** of three squared class errors, not divided by three.
Five-fold means/SD (`ddof=0`) and pooled OOF metrics are kept separate.
AUC is undefined (`null`) when all three classes are not present.

For inference on prepared epochs:

```python
import torch
from models.BRAINet import BRAINet
from dataset.dataset import load_dataset, epoch_zscore
from operate import predict

x, y, subject_id, apen = load_dataset("data/epochs_apen.npz")
model = BRAINet()
checkpoint = torch.load("results/brainet/fold_1/final.pt", map_location="cpu", weights_only=True)
model.load_state_dict(checkpoint["state_dict"])
probabilities = predict(model, epoch_zscore(x), apen)
```

For an unbiased evaluation, infer only on patients held out from that checkpoint.
`model(x, apen, return_details=True)` also returns the fused representation and
four attention tensors `(batch, heads, regions, regions)`. Region order is
frontal, central, parietal, occipital, temporal. Attention is a model weight,
not an estimate of physiological connectivity.
